Reminders

iPhone web apps can't reliably send scheduled notifications without a push server, which this app deliberately doesn't use. So: add a repeating Calendar event for each time of day, and Calendar will alert you. In the app, overdue doses show as a banner.

Tip: tap a button, then Add All in the calendar sheet. If you change your schedule, delete the old event and add a new one.
